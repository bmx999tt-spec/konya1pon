プライバシーポリシー

制定日: 2026年10月9日

このページは、「今夜の1本スレ」の運営者が使う運用ツール「shorts-auto」（以下「本ツール」）が扱う情報について定めます。

1. 本ツールが使う情報

本ツールは、Google の OAuth 認証で運営者自身が許可した範囲で、運営者が管理する YouTube チャンネルの情報（動画の一覧、再生数などの統計）を読み取ります。運営者以外の方のアカウントや情報にはアクセスしません。

2. 使い方

読み取った情報は、運営者のチャンネルの投稿の振り返りと改善のためだけに使います。広告や、ほかの目的には使いません。

3. 保存と共有

情報と認証の情報は、運営者のパソコンの中にだけ保存します。第三者への販売、提供、共有はしません。

4. Google の方針の遵守

本ツールが Google API から受け取った情報の利用と他のアプリへの移転は、Limited Use の要件を含む Google API Services User Data Policy に従います。

5. 許可の取り消し

本ツールへの許可は、Google アカウントの「サードパーティ製のアプリとサービス」からいつでも取り消せます。

6. 変更

このポリシーを変更するときは、このページを更新します。

7. お問い合わせ

YouTube チャンネル「今夜の1本スレ」からご連絡ください。
